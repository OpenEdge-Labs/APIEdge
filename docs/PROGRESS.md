## 2026-10-31: T-001/T-019 fix: per-target environment markers in the lock files

**Defect.** CI run 41226967643 failed on every Python 3.11 and 3.12 test job and on the quality job, at
the developer-install step. Cause: the lock files had no markers and were resolved only on
Windows/Python 3.10, so `backports-asyncio-runner==1.2.0` (Requires-Python <3.11) was required
everywhere. The installer smoke test passed only because it uses `runtime.lock`, whose extra packages
happened to be installable everywhere.

**Fix.** `scripts/update-locks.py` now walks the dependency graph separately for each of the 15
targets, emits PEP 508 markers, adds complementary `dev.lock` entries (`tomli`), and verifies each
target with Requires-Python and wheel checks plus a `pip --dry-run --require-hashes` run (45 runs,
all ok). New unit tests are in `tests/unit/test_update_locks.py`. Local results: 43 tests pass; ruff,
mypy and bandit are clean; pip-audit is unchanged.

### 2026-11-01 - T-007 Gateway runtime

**Summary.** Data plane as a separate Starlette app on `APIEDGE_GATEWAY_PORT` (default 8081),
served by `apiedge run` together with the console in one event loop. Requests
`/<tenant slug><base path><route path>` are resolved against an immutable routing snapshot
(longest base path, segment-wise; `{name}` and final `/*` routes; 404/405 with `Allow`), then
forwarded with smooth weighted round-robin, the API's timeout (504), retries on another upstream
(connection failures for all methods, timeouts and 502/503/504 for idempotent methods only),
verified TLS 1.2+ (optional CA bundle, no switch to disable), hop-by-hop headers stripped both
ways, `X-Forwarded-For/Host/Proto/Prefix` and `X-Request-ID`, a 10 MiB body limit (413), dot
segments refused (400) and fixed JSON errors. Lifecycle: published served; deprecated API or
product flagged `Deprecation: true`; retired API or product 410; draft and inactive tenants 404.
SSRF guard re-applied at connect time below httpx's pool (resolve, check every address, connect to
a checked address with Host/SNI unchanged: DNS rebinding); redirects not followed; proxy env vars
ignored. Hot reload: an `after_commit` hook on the admin session factory publishes a data-less
event through `ConfigBus` (in-process) or `RedisConfigBus` (`APIEDGE_REDIS_URL`, pub/sub with
reconnect), plus a periodic reload (30 s); failed reloads keep the previous snapshot. Admin API
returns `gateway_path`; the console shows it for published/deprecated APIs; system settings list
the gateway settings. ADR 0007, guide `docs/user-guide/gateway.md`.

## 2026-11-02 - T-012 Packet inspector

**Summary.** Opt-in, time-boxed traffic capture per API (optionally one route or consumer). The
gateway's T-008 trace listener now receives the final response and may return a body tap; the
new `CaptureRecorder` copies matching exchanges (request/response line, headers, bodies up to a
cap, timings, upstream and attempts, policy trace) into a byte-bounded queue and a background
task writes them AES-256-GCM encrypted, keeps a per-session ring buffer and purges after the
retention period. Admin API `/api/v1/tenants/{id}/inspector`: sessions (start/stop/delete),
exchanges with filters, SSE live stream, detail (masked; unmasked with `inspector:unmask`,
audited), HAR 1.2 export, replay to the API's own upstream through the SSRF guard. Console
**Packet inspector** page (capture form, session table, filters, live toggle, detail pane with
trace, HAR, replay, unmask). Migration 0007, ADR 0010, Packet Inspector Guide.
