# APIEdge Progress Log

## 2026-10-31: T-001 Project scaffolding + T-019 One-click installer

**Summary.** Delivered the Python/FastAPI foundation and the per-OS one-click installers. Mid-task, the
customer replaced the original T-019 (vendor every wheel and npm tarball into `vendor/`) with an online,
hash-locked installer. No third-party wheel or tarball was ever downloaded into the repository,
committed or pushed.

**Built**
- `pyproject.toml` (setuptools, Apache-2.0), package `src/apiedge`: `config` (pydantic-settings,
  `APIEDGE_*`, platformdirs data dir), `app` (FastAPI factory, `/healthz`, `/readyz`, OpenAPI at
  `/api/v1/openapi.json`, docs UI only in development, console mounted at `/`), `cli`
  (`init`, `migrate`, `run [--open]`, `create-admin`, `version`), `db` (SQLAlchemy 2, Alembic env +
  migration 0001 `users`), `security.passwords` (Argon2id).
- `console/`: React 18 + Vite 6 + TypeScript 5.9 shell (24 npm packages, 0 vulnerabilities), built into
  `src/apiedge/static` (committed).
- `requirements/{runtime,dev,build}.in` → `.lock` (sha256 of every PyPI file for every pin), generated by
  `scripts/update-locks.py`, which also verifies wheel coverage for 5 platforms x Python 3.10-3.12.
- Installers: `install.bat` → `scripts/install.ps1`, `install.command` / `install.sh` →
  `scripts/install.sh`, all → `scripts/install.py` (stdlib only).
- `scripts/check-licenses.py` + `THIRD_PARTY_LICENSES.md` (79 Python packages, 0 forbidden licenses).
- CI `.github/workflows/ci.yml`: quality (ruff, format, mypy, bandit, pip-audit x2, licenses), tests
  (3 OS x 3 Python), installer smoke test (3 OS: install, re-install, uninstall), console build freshness.
- Docs: `docs/ARCHITECTURE.md`, ADR 0001 and 0002, `docs/installation.md`,
  `docs/admin-guide/configuration.md`, README quick start, `.env.example`, `.pre-commit-config.yaml`.

**Verification (local, Windows 11, Python 3.10.4)**
- ruff check + format: pass. mypy --strict (30 files): pass. bandit (src, scripts): 0 issues.
- pytest: 36 passed.
- pip-audit runtime.lock: no known vulnerabilities. dev.lock: 17 filelock CVEs, dev-only and documented
  in `requirements/audit-ignore-dev.txt` (the fix needs Python 3.11 or newer).
- `npm audit`: 0 vulnerabilities. `tsc --noEmit`: pass. The console build is deterministic.
- `install.bat --yes --smoke-test` on a fresh venv: pass (`/healthz` 200, console 200). A re-run
  repairs (venv reused, admin kept) and passes. `--uninstall --purge-data` removes everything.
- The install log contains no generated admin password (checked).
