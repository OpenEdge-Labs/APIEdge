# Admin API reference

APIEdge Admin API, version `0.1.0.dev0`, OpenAPI `3.1.0`. The machine-readable document is [openapi.json](openapi.json) (also served by every installation at `/api/v1/openapi.json`). How to authenticate, CSRF, errors and conventions are explained in the [Admin API guide](index.md).

**Access** names the permission an operation needs. Tenant routes answer `404` when the caller does not belong to the tenant, and `403 permission_denied` when the permission is missing. Some operations check more inside (for example the product a request touches); their descriptions say so.
